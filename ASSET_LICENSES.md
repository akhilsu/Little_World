# Asset Licenses

## Current release

This project does not bundle third-party photographs, illustrations, fonts, music, or sound recordings.

- Visual characters and objects use platform-rendered Unicode emoji.
- Shapes, scenery, controls, and animation are authored in CSS.
- Spoken feedback uses the browser and operating system's local Speech Synthesis implementation.
- Music notes and short feedback effects are generated locally with the Web Audio API.
- `public/favicon.svg` comes from the OpenAI Sites starter included with the local project scaffold.

No runtime asset is loaded from a CDN or external URL.

## Adding assets later

For every added file, record its filename, creator, source URL, license name, license URL, and any attribution text required. Only use files whose license permits local redistribution.
